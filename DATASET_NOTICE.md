# Dataset and model notice

The included Colab notebook downloads the public PlantVillage dataset through TensorFlow Datasets and downloads MobileNetV2 ImageNet weights through Keras. Review the upstream dataset and pretrained-weight terms before redistribution. This ZIP contains neither PlantVillage images nor pretrained disease weights.

The previously uploaded image-classification project includes flower images and a classifier with labels `00`, `01`, `02`; those are not disease labels and are deliberately not reused for disease predictions.
